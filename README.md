# Movie_Recommendation_model
Data preprocessing and analysing the data to get the answer for 4 major questions.

1. Most frequent Genre of Movies Released on Netflix
2. Highest votes in the vote average column.
3. Movie with the lowest and the highest propularity and their genre
4. Year in which the highest number of movies are released

5. Libraries used
  a. Numpy
  b. Pandas
  c. Matplotlib(pyplot)
  d. Seaborn
